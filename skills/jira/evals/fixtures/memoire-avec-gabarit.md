# Versioning Control System (VCS) Guidelines

Mémoire minimale d'un dépôt d'essai. Ne porte que ce dont l'action de publication a besoin.

- Ticketing Tool : Jira, site `exemple.atlassian.net`

## Tickets Jira

**Projets Jira ouverts en écriture** : `DEMO` (Démo).

**Gabarits de description Jira** : `aidd_docs/memory/templates/jira/<type>.md`. Ils surchargent les
défauts du skill. Un type sans fichier ici tombe sur le défaut du skill, ce qui est le cas normal.

**Le champ qui porte la clé du ticket** est `tracker`, écrit à la publication.

**Rien ne part dans Jira sans demander.** Ce dépôt d'essai ne déclare aucun garde à jeton.
