# Style chat / terminal

Le contenu vit dans la couche globale de règles, pas ici : `style.md` pour le noyau, `profil.md` pour le ton et la voix, `reponse.md` pour le médium chat, `redaction.md` pour l'écriture sur support, `ponctuation.md` pour la ponctuation de prose.

**POURQUOI presque vide** : un critère laissé ici ne traverse ni les sous-agents ni un autre wrapper. Ce fichier ne garde que ce qui est propriétaire de l'outil.
